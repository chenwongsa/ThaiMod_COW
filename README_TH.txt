================================================================
  มอดแปลภาษาไทย theHunter: Call of the Wild (ฉบับสมบูรณ์)
  โดย Wild Horizon Gaming
================================================================

มอดนี้แปลเกม theHunter: Call of the Wild เป็นภาษาไทยทั้งเกม
- เมนู / HUD / หน้าจอทั้งหมด
- ภารกิจหลัก-รอง และบทสนทนาทุกแมพ
- สารานุกรมสัตว์ อาวุธ อุปกรณ์ ความสามารถ
- ฟอนต์ไทยในตัว + โลโก้หน้าเมนูภาษาไทย
- ตรวจทานคำศัพท์เฉพาะทางการล่าสัตว์ทั้งเกมด้วยระบบ AI + ทีมงาน

รองรับ: ทั้ง Epic Games Store และ Steam (ทดสอบจริงทั้งสองเวอร์ชัน —
        ไฟล์เกมเหมือนกันทุกไบต์ ตัวติดตั้งตรวจจับ store ให้อัตโนมัติ
        ถ้าเกมอัปเดตจนไฟล์ไม่ตรงรุ่น ตัวติดตั้งจะไม่ยอมติดตั้งเพื่อความปลอดภัย)

----------------------------------------------------------------
  วิธีติดตั้ง
----------------------------------------------------------------
1. ปิดเกมให้สนิท
2. เปิดโฟลเดอร์ ThaiMod_Installer_WildHorizonGaming
   แล้วดับเบิลคลิก ThaiMod_Installer_WildHorizonGaming.exe
   * ถ้า Windows SmartScreen เตือน: กด "More info" → "Run anyway"
     (เป็นเรื่องปกติของโปรแกรมที่ยังไม่ได้ซื้อใบรับรอง ไม่ใช่ไวรัส)
   * ถ้าเกมอยู่ใน C:\Program Files ให้คลิกขวา → Run as administrator
3. โปรแกรมจะหาโฟลเดอร์เกมให้อัตโนมัติ (หรือกด "เลือก..." เลือกเอง)
4. รอสถานะขึ้นสีเขียว "พบเกม COTW" แล้วกด "ติดตั้งมอด (INSTALL)"
5. เสร็จแล้วเปิดเกมได้เลย — เกมจะเป็นภาษาไทยทันที

โปรแกรมจะสำรองไฟล์เดิมไว้ให้อัตโนมัติ (โฟลเดอร์ _thaimod_backup)

----------------------------------------------------------------
  วิธีถอนการติดตั้ง (กลับเป็นภาษาอังกฤษ)
----------------------------------------------------------------
- เปิดตัวติดตั้ง → กด "ถอนการติดตั้ง (คืนค่าเดิม)"
- หรือใช้ Verify Files ของ Epic/Steam ก็ลบมอดออกได้เช่นกัน
  (Epic: Library → ... → Manage → Verify
   Steam: คลิกขวาเกม → Properties → Installed Files → Verify)

----------------------------------------------------------------
  เมื่อเกมอัปเดตเวอร์ชันใหม่
----------------------------------------------------------------
1. อย่าเพิ่งกด INSTALL ทับ! ให้ Verify Files ในสโตร์ก่อน
   (ตัวติดตั้งตรวจพบเกมที่ถูกอัปเดตและจะเตือน/บล็อกให้อยู่แล้ว)
2. Verify เสร็จ → เปิดตัวติดตั้ง → กด INSTALL ใหม่
3. ถ้าเวอร์ชันใหม่ไฟล์เปลี่ยนจนมอดไม่รองรับ ตัวติดตั้งจะปฏิเสธ
   ให้รอมอดเวอร์ชันอัปเดตจากเพจ Wild Horizon Gaming

----------------------------------------------------------------
  คำถามพบบ่อย
----------------------------------------------------------------
ถาม: เซฟเกมหายไหม?
ตอบ: ไม่หาย — มอดแก้เฉพาะไฟล์ข้อความ/ฟอนต์ ไม่แตะเซฟเกมเลย

ถาม: เล่นออนไลน์/มัลติเพลเยอร์ได้ไหม?
ตอบ: ได้ มอดเป็นฝั่งเครื่องเราเท่านั้น ผู้เล่นอื่นไม่เห็นผลกระทบ
     (แนะนำทดสอบครั้งแรกกับเพื่อนก่อน)

ถาม: ติดตั้งแล้วเกมเปิดไม่ขึ้น/ตัวหนังสือเพี้ยน?
ตอบ: กด "ถอนการติดตั้ง" หรือ Verify Files แล้วติดตั้งใหม่อีกครั้ง
     ถ้ายังไม่หาย แจ้งเพจพร้อมภาพหน้าจอ

ถาม: EULA/นโยบายความเป็นส่วนตัวในเมนูตั้งค่าเป็นภาษาอังกฤษ?
ตอบ: ตั้งใจคงไว้ — เอกสารกฎหมายต้องแสดงฉบับเต็มตามต้นฉบับ

----------------------------------------------------------------
